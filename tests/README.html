Test Layout Policy

Tests are created as part of each TDD slice. This project starts with separate unit and integration roots.

Folders

  • tests/unit: pure functions, validation, parsing, deterministic routing, and isolated state transitions.
  • tests/integration: behavior across boundaries such as event intake to raw log append.

Rules

  • Write only the tests needed for the active functional spec.
  • Prefer fast unit coverage for pure contracts before integration coverage.
  • Integration tests should prove module collaboration without depending on live model providers.
  • Each implementation journal must list the tests run and the result.
