This page preserves the historical planning target for the TypeScript migration stages that preceded the source-of-truth cutover. It exists so older stage journals do not link to the mutable active slice after docs/plan/active-slice.html moved on to the cutover slice.

Historical Scope

  • Use TypeScript source and Vitest tests as a parity implementation until the final cutover.
  • Keep Python source and tests untouched while they acted as the behavior oracle.

The migration stages are complete and the branch now treats TypeScript as the implementation source of truth. Current evidence and cutover status live in the TypeScript source-of-truth tracker.
