Completed Plans

Plan Status Scope
MVP-021 - Minimal Durable User Interruption Boundary Implemented and merged; PR #24. Commit one deterministic USER_MESSAGE interruption policy outcome through Commit & Effects. "interruptible" moves the scoped active_incident to interrupted_incident and exposes life_incident_interrupted; "background" and "protected" expose query-visible policy logs while leaving the active incident unchanged.
MVP-020 - Computed User Interruption Context Implemented and merged; PR #23. Add one read-only computed character_snapshot.user_message_interrupted_active_incident flag when a USER_MESSAGE context includes an active incident, without durable interruption status, resume behavior, new commit transition, scheduler, body, or Live2D changes.
MVP-019 - Minimal Incident Completion RuntimeEvent Boundary Implemented and merged; PR #22. Add a narrow INCIDENT_COMPLETION RuntimeEvent with incident_id, route it without a model call, and commit matching active-incident completion through Commit & Effects with structured rejection logs.
MVP-018 - Minimal Complete Active Incident Commit Boundary Implemented and merged; PR #21. Let an opted-in USER_MESSAGE turn complete the currently active incident through Commit & Effects and InMemoryLifeIncidentStore, with a query-visible life_incident_completed raw log and no private completion event, scheduler, body, Live2D, or follow-up incident behavior.
MVP-017 - Minimal Cancel Active Incident Commit Boundary Implemented and merged; PR #20. Let an opted-in USER_MESSAGE turn cancel the currently active incident through Commit & Effects and InMemoryLifeIncidentStore, with a query-visible life_incident_cancelled raw log and no extra lifecycle behavior.
MVP-016 - Role Model Input Envelope Split Implemented and merged; PR #19. Split the outer RoleModelInputEnvelope from the inner compact DecisionContext by moving call_type, current event, and allowed_actions out of the context while preserving current USER_MESSAGE model-call behavior.
MVP-015 - Character State Engine Context Builder Boundary Implemented and merged; PR #18. Move source orchestration for recent visible messages, living_state_brief, and active_incident behind a Character State Engine context-builder boundary while preserving the current broad DecisionContext shape as a deliberate compatibility step.
MVP-014 - Minimal Concrete LifeIncidentStore Start Adapter Implemented and merged; PR #16. Replace the MVP-012 incident-start recording fake with a small concrete in-memory LifeIncidentStore start adapter that stores the active incident, implements the existing ActiveIncidentSource read contract, and exposes the matching life_incident_started entry through the MVP-013 query surface, without adding the rest of the incident lifecycle.
MVP-013 - Raw Event Log Query/Replay Visibility for Committed Success Logs Implemented and merged; PR #15. Prove success logs exposed through MVP-010 and MVP-012 atomic finalizers are visible through the same Raw Event Log query/debug surface as ordinary appended logs, without adding concrete storage, replay execution, debug UI, or new runtime behavior.
MVP-012 - Minimal Start Incident Commit Boundary Implemented and merged; PR #13. Parser coverage follow-up merged in PR #14. Allow an opted-in USER_MESSAGE turn to parse and commit one optional life_action.start_incident through an injected fake finalizer, without complete/cancel/resume, interruption policy, concrete incident storage, body, retrieval, tools, Live2D, or new event types.
MVP-011 - Read-Only Active Incident Brief in DecisionContext Implemented and merged; PR #12. Add one optional injected active-incident source and one compact character_snapshot.active_incident brief to the existing USER_MESSAGE role-model context, without lifecycle writes, interruption policy, queues, body, retrieval, tools, Live2D, or new event types.
MVP-010 - Atomic Living State Patch Commit Boundary Implemented and merged; PR #10. Follow-up review fixes in PR #11. Atomize the successful living-state patch path so the validated state snapshot and matching living_state_patch_committed raw log entry become visible together through one injected fake boundary, without concrete storage, state versions, body, incidents, retrieval, tools, Live2D, or new event types.
MVP-009 - Minimal Living State Patch Commit Implemented and tested; PR #9 Allow an opted-in USER_MESSAGE turn to parse one optional state_patch.living_state and commit it through an injected Commit and Effects state boundary, without concrete storage, body, incidents, retrieval, tools, Live2D, or new event types.
MVP-008 - Read-Only Living State Snapshot in DecisionContext Implemented and tested; PR #8 Add one optional injected current-state source and one compact living_state_brief to DecisionContext.character_snapshot for USER_MESSAGE turns, without state mutation, concrete storage, body, incidents, retrieval, tools, Live2D, or new model actions.
MVP-007 - Minimal User Turn Orchestrator Implemented and tested; PR #7 Route USER_MESSAGE to model_needed = true / next_step = "user_turn", then compose Runtime Kernel intake, user visible projection, recent visible source, Role Model Loop, and assistant visible reply commit with fakes and injected boundaries.
MVP-006 - Visible Conversation Recent Source Implemented and tested; PR #6 Map committed visible user and assistant records into the existing RecentVisibleMessage context shape through an injected read-only source, without concrete storage, orchestration, model calls, retrieval, or state.
MVP-005 - User Visible Message Projection Implemented and tested; PR #5 Project a normalized USER_MESSAGE into the visible conversation boundary with one raw projection log and one injected visible append, without concrete storage, orchestration, model calls, retrieval, or state.
MVP-004 - Recent Visible Messages in DecisionContext Implemented and tested Add a bounded recent visible message tail to DecisionContext through an injected read-only source, without concrete storage, retrieval, orchestration, or new model actions.
MVP-003 - Minimal Visible Reply Commit Implemented and tested Validate an MVP-002 visible_reply decision, append one internal visible output, append commit/reject raw logs, and return a deterministic commit result.
MVP-002 - Minimal Role Model Loop with Fake Adapter Implemented and tested Build a minimal current-event DecisionContext, call an injected fake model adapter through the Role Model Loop, parse a visible_reply-only decision, and log the model turn.
MVP-001 - Runtime Event Intake and Raw Logging Implemented and tested Accept a USER_MESSAGE RuntimeEvent, assign event and trace IDs, append one raw log entry, and return a deterministic route without calling a model.
Project initialization functional spec Implemented Create local docs, test roots, source root, and development rules without runtime code.
