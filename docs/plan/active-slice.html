TypeScript Runtime Source of Truth Cutover

Status: active implementation slice

Created: 2026-05-30. Active branch: mvp-typescript-shadow-port. Preserved Python branch: legacy-python-main created from local main before Python removal.

Source Context

Product direction remains the Notion project hub Live Character Framework and the original TypeScript migration goal. Local implementation truth for the completed port is recorded in the TypeScript source-of-truth tracker and the 2026-05-29/2026-05-30 development journals.

Source-of-truth note: the original Notion migration goal framed the work as a shadow port with Python remaining production truth. After the complete port passed review gates, the user approved a two-branch cutover: keep Python on legacy-python-main and make this branch the TypeScript source-of-truth line. This PR must call out that approved exception explicitly because it intentionally exceeds the original shadow-port-only wording.

Goal

Promote the completed TypeScript runtime from a shadow implementation to the branch's source of truth. The production tree should use src/ and tests/ for TypeScript, CI should run TypeScript-only gates, package metadata should describe the TypeScript runtime, and local docs should make clear that the Python implementation now lives on legacy-python-main.

  • Create legacy-python-main from current local main.
  • Remove the Python src/ and tests/ trees from this TypeScript branch.
  • Remove stale Python-only tooling metadata from this TypeScript branch.
  • Move TypeScript source from src-ts/ to src/.
  • Move TypeScript tests from tests-ts/ to tests/.
  • Update imports, TypeScript config, Vitest config, ESLint config, and package scripts for the new paths.
  • Update CI so the existing lint, typecheck, and test jobs are TypeScript-only.
  • Update package metadata from migration wording to TypeScript runtime wording.
  • Update active docs, plan index, source-of-truth tracker, future-slice notes, and journal with cutover evidence.
