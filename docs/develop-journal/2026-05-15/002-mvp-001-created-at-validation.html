MVP-001 Created At Validation

Date: 2026-05-15

What Changed

  • Updated src/runtime/kernel.py to distinguish absent created_at from explicit null.
  • Rejected provided created_at strings that parse as date-only values without a datetime component.
  • Added unit coverage in tests/unit/test_runtime_kernel.py for explicit null and date-only created_at.
  • Added integration coverage in tests/integration/test_runtime_kernel_intake_logging.py so malformed event times do not append raw log entries.
  • Clarified the active slice normalization rule in docs/plan/active-slice.html.

Why It Changed

A review found that provided created_at validation was too permissive. The active contract only generates a clock timestamp when the field is absent. Once callers provide the field, the value must be a timestamp string rather than null or a date-only string.
