TypeScript-Native Decisions

  • Keep runtime records in snake_case while exposing TypeScript structural interfaces with camelCase method names.
  • Use explicit committed, skipped, protected/background, and rejected result unions rather than broad untyped objects.
  • Use injected clock and ID generators for deterministic commit times and raw-log IDs.
  • Use InMemoryRawEventLog atomic expose/confirm/discard behavior for committed success logs instead of appending success entries directly.
  • Use handwritten validators and existing contract helpers to preserve Python extra-key rejection and runtime validation semantics.
