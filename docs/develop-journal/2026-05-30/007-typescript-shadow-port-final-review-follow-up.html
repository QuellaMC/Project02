  • Aligned unexpected cancel, complete, and interruption finalizer failures with Python rejected-result behavior while preserving malformed raw-log validation as malformed_finalize_result.
  • Followed the final incident review by mapping RawEventLogQueryValidationError from cancel/complete direct finalizers, cancel/complete post-visible hooks, and interruption direct finalizers to malformed_finalize_result.
  • Aligned lifecycle complete/interruption rejection behavior so invalid source-event types with trusted IDs produce rejected results and raw logs instead of escaping before the commit-validation path.
  • Added explicit ISO string clock support so TypeScript can preserve non-UTC offsets and fractional precision when a port path already owns an ISO timestamp.
  • Added regression coverage for concrete incident-store absence, malformed route inputs, nested non-cloneable raw-log data, generated Date timestamp normalization, explicit string-clock offset preservation, invalid lifecycle source-event types, and unexpected finalizer failures.

TypeScript-Native Decisions

  • Generated TypeScript timestamps from JavaScript Date are normalized to Python's +00:00 output shape. Explicit ISO string clocks preserve non-UTC offset text and fractional precision for port paths that already own a timestamp string.
  • The incident lifecycle helper remains internal to concrete TypeScript commit modules. Exporting a generic public helper would widen the shadow-port API beyond the current active slice.
  • Interruption post-visible hook RawEventLogQueryValidationError remains finalize_rejected because Python src/commit_effects/incident_interrupt.py does not special-case that hook the way the shared cancel/complete lifecycle helper does.
  • Python source, Python tests, and production routing remain untouched. Python removal and branch renaming are recorded as a future production cutover, not performed in this shadow-port follow-up.
