2026-05-31 - Staged Commit Transaction Helper

What Changed

  • Created the active slice spec for the P2 staged commit transaction helper refactor.
  • Added runStagedCommitTransaction in src/commit-effects/incident-lifecycle.ts.
  • Refactored incident start, cancel, complete, interrupt, and living-state commit paths to reuse the shared finalizer, success-log visibility, post-visible, and staged-discard sequence.
  • Added helper regression coverage in tests/unit/commit-effects/incident-lifecycle.test.ts.
  • Parked follow-up ideas for shared finalize result validation, living-state raw-log requirement hooks, and interruption post-visible semantics.

Why

The concrete commit-effect modules repeated the same staged transaction flow: invoke the finalizer, validate the result, confirm committed success-log visibility, run post-visible completion when present, and discard staged success visibility on pre-visible failures. The refactor keeps the Commit & Effects boundary local while removing repeated control flow.
