2026-05-31 - Context Provider Sections

What Changed

  • Replaced the stale active slice with Context Provider Sections.
  • Added an optional DecisionContext.context_sections envelope for provider-owned compact context outside character_snapshot.
  • Added a DecisionContextSectionProvider option and deterministic request shape for user-message context building.
  • Forwarded the provider option through the Role Model Loop.
  • Added focused tests for provider inclusion, copy safety, malformed section rejection, direct context validation, and rendered role-model input.
  • Parked retrieved-context provider work in future slices.

Why

The previous DecisionContext shape forced every context source into a fixed character-specific snapshot. Notion's context direction calls for compact selected context from multiple systems, including future retrieval, while keeping raw stores and retrieval mechanics separate from the model-facing view.
