Why

Review Notes

  • MVP-017 is intentionally cancel-only. It does not add complete, resume, go-idle, no-change, interruption, queues, body effects, Live2D, scheduler, retrieval, or persistent storage.
  • The key safety requirement is atomic state/log visibility: no active incident may be cleared unless life_incident_cancelled is query-visible through the Raw Event Log surface.
  • The spec explicitly requires Commit & Effects to re-read and match the current active incident ID before finalizing cancellation.
