MVP-005 Structured Role-Model User Turn Drafted For Review

Created branch feature/mvp-005-structured-role-model-user-turn, archived the completed MVP-004 durable local runtime continuity slice, and drafted MVP-005 as the proposed next active slice for review. The new draft frames the next product step as the first structured role-model user-turn foundation for the existing durable local chat path.

After this slice, the same visible chat path should route through a compact DecisionContext, RoleModelInputEnvelope, local/fake role-model adapter, parsed CharacterDecision, and commit/effects validation boundary.
