Installing Project02

Project02 is an app for Windows, macOS and Linux: a window to talk to the characters in, and an icon in the tray that keeps them answering in Telegram while the window is closed. The character service and the Telegram connector run inside it, so there is nothing else to start.

Getting it

Take the file for your system from the releases page:

System The file Then
Windows Project02_…_x64-setup.exe Open it. It installs the app for you alone, with no administrator, and fetches WebView2, which shows the app's page, when your Windows lacks it.
macOS Project02_…_aarch64.dmg for a Mac with Apple silicon, Project02_…_x64.dmg for one with an Intel processor; About This Mac names the chip. Open the disk image and drag Project02 into Applications.
Linux Project02_…_amd64.AppImage, or Project02_…_amd64.deb Mark the AppImage executable and run it, or install the deb.

Opening it the first time

The app is not signed yet, so Windows and macOS each stop it once, in their own words, before it opens. Before that, a browser may warn that the file isn't commonly downloaded: keep it.

  • Windows says Windows protected your PC. Press More info, then Run anyway.
  • macOS says it cannot verify the app: Apple could not verify “Project02” is free of malware… Open System Settings, then Privacy & Security, scroll to the message about Project02, press Open Anyway, and confirm once more. It asks once for each version.

The first run

A window opens within about a second on Set up your home: choose how your character thinks and paste the key it needs, say what to call you, then open the chat. An icon appears in the tray, or on a Mac in the menu bar; Windows 11 may keep it behind the taskbar's arrow until you drag it out.

Telegram

To talk to a character in Telegram too, open its settings, the ⚙ beside its name, and paste its bot's token, as @BotFather gave it, into Bot token under Messaging apps. The connector is already running, and the Telegram block says so: Connector: running.

Later

Closing the window does not quit: the characters keep answering in Telegram, and Open Project02 in the tray, the Dock, or opening the app again brings the window back. Quit from the tray, or on a Mac from the application menu or with Cmd-Q, when you mean it. A new version is a new download from the releases page, installed over the old one as the first was; nothing said is lost.

Where things are

Everything said and every setting is kept in the home, outside the app: installing, updating and uninstalling the app leave it as it is.

  • The home is %APPDATA%\Project02 on Windows, ~/Library/Application Support/Project02 on macOS, and ~/.local/share/project02 on Linux, or $XDG_DATA_HOME/project02 where that is set. Open data folder in the tray shows it.
  • The logs are daemon.log, the character service's, and telegram.log, the connector's; Open logs in the tray opens their folder. When the character service cannot start, a dialog says so with the end of daemon.log and where the whole log is, and the app quits.
  • The third-party notice, THIRD-PARTY-NOTICES.txt, ships with the app: what it is built from, with the text of each license.

For a developer

The app changes nothing in a checkout: project02 serve, project02 telegram and project02 inspect work on .project02 in the folder they run from, the checkout's root under pnpm serve and pnpm inspect. Where a webview's development files are installed, as crates/project02-shell/README.md lists them, cargo run -p project02-shell -- --store .project02, after pnpm build:web, runs the app on that same home. project02 inspect --store <home> reads an installed app's home, given its path from the list above.
