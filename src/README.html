Source Layout Policy

This directory is the future source root. It intentionally contains no runtime implementation modules yet.

Rules

  • Create a module directory only when a reviewed functional spec and failing tests require it.
  • Before adding code, check whether the behavior is already implemented or belongs in an existing module.
  • Use shared code only for stable cross-module boundaries, not speculative convenience.
  • Keep the four top-level runtime responsibilities clear: Runtime Kernel, Character State Engine, Role Model Loop, and Commit and Effects Engine.

Expected First Runtime Area

The first likely source module will support the smallest Phase 1 behavior: USER_MESSAGE RuntimeEvent intake, trace creation, deterministic routing, and raw event log append through an interface.
