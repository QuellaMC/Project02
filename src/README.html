Source Layout

src/ is the TypeScript runtime source root for Project02. The Python runtime was preserved on legacy-python-main during the TypeScript source-of-truth cutover.

Boundaries

  • src/runtime/: event contracts, raw logging, Runtime Kernel, validation, schema, and user-turn orchestration.
  • src/character/state/: current state, incident state, and compact decision-context building.
  • src/role-model/: model-input rendering, adapter boundary, model-output parsing, and decision validation.
  • src/commit-effects/: visible conversation, living-state, incident lifecycle, and effect commit boundaries.
