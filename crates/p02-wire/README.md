# p02-wire

Every type that crosses the daemon's socket: each route's body and
answer, each frame of the event stream and the `ready` snapshot, and every
type those reach. The daemon makes these values and a client reads them,
the Telegram connector with these very types, so a client links this crate
and nothing of the daemon. It depends on p02-core and p02-shared alone.

A view's screen on her phone is one of these types: the phone reads what
an app shows into it, so what her window draws is what she reads.

These types are the wire's contract. `cargo test -p p02-gateway contract`
writes `packages/wire/src/contract/generated/` from them: the TypeScript
the page compiles against, and the JSON Schema the conformance suite holds
every answer and frame to. After a change here, run it and commit what it
writes.
